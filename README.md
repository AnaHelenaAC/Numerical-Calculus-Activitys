# Numerical-Calculus-Activitys

Este repositório é um portfólio de atividades práticas e implementações de algoritmos desenvolvidos para a disciplina de Cálculo Numérico. O objetivo central é traduzir métodos matemáticos em código estruturado e eficiente, construindo a lógica do zero e minimizando o uso de funções nativas de alto nível.

---

## 🗂️ Índice de Atividades

Abaixo estão listados os projetos e módulos desenvolvidos ao longo da disciplina:

### 1. [Mudança de Base Numérica](./Atividade_de_Mudanca_de_Base)
Implementação matemática em **Java** para a conversão bidirecional entre bases numéricas arbitrárias (de base 2 a 36) e a base decimal.
*   **Algoritmo 1 (Base para Decimal):** Converte uma *string* da base de origem para um valor inteiro utilizando o método de **expansão polinomial**.
*   **Algoritmo 2 (Decimal para Base):** Converte um inteiro decimal para uma *string* na base de destino aplicando o método de **divisões sucessivas**.
*   **Destaques Técnicos:** Tratamento rigoroso de erros com `IllegalArgumentException`, otimização de mutação de *strings* utilizando `StringBuilder` e motor isolado de testes automáticos para validação da integridade bidirecional.
